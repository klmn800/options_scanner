## Migration History

**Initial Migration (October 27, 2025):**
- Phase 1: Migrated data from expiration-based archives into sector-based databases
- Phase 2: Aligned all schemas to match production datalake.db
- Table names standardized: `flow_options_scans`, `option_contracts`, `flow_alerts`, `flow_symbol_summary`, `option_symbol_summary`
- Column names modernized: `dte` (not days_to_expiration), `iv` (not implied_volatility)

**Ongoing (since November 2025):**
- Archives receive weekly updates every Friday via `db_archive_sector.py`
- Two new sectors added post-migration: `defense.db`, `nuclear.db`
