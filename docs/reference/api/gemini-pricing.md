# Gemini API Pricing Overview

## Key Pricing Highlights
- Free tier available through API service with lower rate limits
- Google AI Studio usage is completely free
- Paid tier offers higher rate limits and additional features

## Model Pricing Tiers

### Gemini 2.5 Pro (Standard)
- Input Price (Paid Tier):
  - $1.25 per 1M tokens (≤ 200k tokens)
  - $2.50 per 1M tokens (> 200k tokens)
- Output Price (Paid Tier):
  - $10.00 per 1M tokens (≤ 200k tokens)
  - $15.00 per 1M tokens (> 200k tokens)

### Gemini 2.5 Flash (Standard)
- Input Price (Paid Tier):
  - $0.30 per 1M tokens (text/image/video)
  - $1.00 per 1M tokens (audio)
- Output Price (Paid Tier):
  - $2.50 per 1M tokens

### Batch Mode Pricing
- Requests processed asynchronously are 50% cheaper than interactive requests
- Example: Batch mode for Gemini 2.5 Flash has lower input/output prices

## Additional Pricing Notes
- Context caching available in paid tier
- Google Search grounding has free and paid tiers
- Preview models may have more restrictive rate limits

## Billing Options
- Free tier: Used to improve Google products
- Paid tier: "No" to using data for product improvement

*Prices subject to change; refer to official documentation for most current rates.*
