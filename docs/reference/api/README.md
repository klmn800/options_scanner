# API Documentation Reference

This directory contains local copies of API documentation for all services used in the options scanner system.

## Contents

- `openai-models.md` - OpenAI API models, pricing, and capabilities
- `anthropic-models.md` - Claude API models, pricing, and capabilities  
- `xai-models.md` - XAI Grok models, pricing, and capabilities
- `gemini-models.md` - Google Gemini models, pricing, and capabilities
- `tradier-api.md` - Tradier trading API endpoints and data formats

## Purpose

These local documentation files serve as:
1. **Offline reference** - Work without internet connectivity
2. **Version control** - Track API changes over time
3. **Backup documentation** - Preserve information if official docs change URLs
4. **Quick reference** - Fast access to model names, limits, and pricing

## Update Schedule

Documentation should be refreshed:
- **Monthly** for pricing and rate limit changes
- **Weekly** for new model releases
- **As needed** when API errors suggest documentation is outdated
